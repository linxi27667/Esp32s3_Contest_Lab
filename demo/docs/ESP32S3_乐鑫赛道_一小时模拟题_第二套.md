# ESP32-S3 乐鑫赛道一小时模拟测评题（第二套）

## 一、测评说明

1. 本题用于模拟全国大学生嵌入式芯片与系统设计竞赛乐鑫赛道现场测评。
2. 测评时间为 60 分钟，满分 100 分。参赛者应在规定时间内完成程序设计、下载和现场演示。
3. 本题不要求使用显示屏。系统状态通过普通 LED、可编程全彩 LED、蜂鸣器及上位机串口进行显示和反馈。
4. 各项功能相互关联，后续功能应在前面功能基础上继续完善，不得破坏已经完成的功能。
5. 除题目明确规定外，不限制任务划分和软件结构。程序运行期间不得因阻塞等待导致按键、Touch、UART 或 ADC 功能失去响应。

## 二、硬件条件

系统使用 ESP32-S3 或 ESP32-P4 开发板，并至少具备以下资源：

1. 四个普通 LED，编号为 LED1、LED2、LED3、LED4。
2. 一个 GPIO 按键，按下时能够产生稳定事件。
3. 一个可连接导电片的 Touch 输入通道。
4. 一颗或多颗 WS2812 类可编程全彩 LED。
5. 一个有源蜂鸣器和一个无源蜂鸣器。
6. 一路 ADC 模拟量输入，连接可调电阻或模拟传感器。
7. 一路与上位机通信的 UART 串口。
8. 至少 1 KB 的 NVS 非易失性存储空间。
9. 可产生单次事件和周期事件的定时器资源。

本工程建议引脚如下：LED1 使用 GPIO1，LED2 使用 GPIO2，LED3 使用 GPIO4，LED4 使用 GPIO5；有源蜂鸣器使用 GPIO6；无源蜂鸣器使用 GPIO7；按键使用 GPIO8；ADC 使用 GPIO9；WS2812 使用 GPIO11；Touch 导电片使用 GPIO14；外部 UART 的 TX、RX 分别使用 GPIO17、GPIO18。若实际开发板引脚不同，以开发板原理图和现场接线为准。

ADC 输入必须满足芯片允许的电压范围。使用 0 至 3.3 V 信号源时，应根据实际 ADC 量程进行分压或标定。

## 三、任务背景

设计一个模拟量监测与报警终端。系统周期采集模拟输入，使用普通 LED 和全彩 LED 显示当前等级；用户可通过按键改变显示方式，通过 Touch 改变报警阈值；当输入超过阈值时，系统进入报警状态，并允许用户通过按键暂时静音。上位机可查询和修改系统配置，用户配置应在掉电后保留。

系统使用以下业务变量：

- `level`：当前模拟量百分比，范围为 0 至 100。
- `threshold`：报警阈值，只允许取 70 或 85。
- `display_mode`：普通 LED 显示方式，只允许取 0 或 1。
- `system_state`：系统状态，取值为 NORMAL 或 ALARM。
- `mute`：本次报警是否已静音，取值为 0 或 1。

## 四、功能要求

### 第 1 题：上电自检与定时启动（10 分）

系统上电后应完成全部外设初始化，并进入持续 3 秒的自检状态：LED1、LED4 点亮，LED2、LED3 熄灭；全彩 LED 显示黄色，亮度为 64；有源蜂鸣器关闭；无源蜂鸣器以 1500 Hz 鸣叫 100 ms。

3 秒到达后，四个普通 LED 全部熄灭，全彩 LED 显示绿色，系统进入 NORMAL 状态，并通过 UART 发送：

`READY\r\n`

3 秒等待必须通过单次定时事件完成，不得使用持续 3 秒的阻塞延时。

### 第 2 题：ADC 周期采样与等级换算（15 分）

ADC 每 100 ms 采样一次，每次采样应获得原始值和换算后的输入电压毫伏值 `mv`。

按照下式计算 `level`：

`level = mv * 100 / 3300`

计算结果应限制在 0 至 100。ADC 读取失败时不得使用本次无效结果改变系统状态。

系统每隔 1 秒通过 UART 主动发送一次采样结果：

`DATA LEVEL=xx MV=xxxx STATE=s\r\n`

其中 `xx` 为 `level`，`xxxx` 为输入电压毫伏值，`s` 为 NORMAL 或 ALARM。

### 第 3 题：普通 LED 和全彩 LED 显示（15 分）

NORMAL 状态下，根据 `display_mode` 显示当前 `level`。

`display_mode` 为 0 时，四个普通 LED 采用柱状显示：

1. `level` 为 0 至 24：四个 LED 全部熄灭。
2. `level` 为 25 至 49：仅 LED1 点亮。
3. `level` 为 50 至 74：LED1、LED2 点亮。
4. `level` 为 75 至 89：LED1、LED2、LED3 点亮。
5. `level` 为 90 至 100：四个 LED 全部点亮。

`display_mode` 为 1 时，四个普通 LED 采用单点显示：

1. `level` 为 0 至 24：仅 LED1 点亮。
2. `level` 为 25 至 49：仅 LED2 点亮。
3. `level` 为 50 至 74：仅 LED3 点亮。
4. `level` 为 75 至 100：仅 LED4 点亮。

NORMAL 状态下，全彩 LED 的颜色要求如下：`level` 小于 50 时显示绿色；`level` 大于或等于 50 时显示黄色。连续超限次数达到报警条件后，才由 ALARM 状态强制显示红色。

### 第 4 题：按键与 Touch 交互（15 分）

按键采用中断方式检测并具备基本消抖能力。一次完整按下只能产生一次有效事件，持续按住不得重复触发。

NORMAL 状态下，每次有效按键事件使 `display_mode` 在 0 和 1 之间切换。切换成功后，无源蜂鸣器以 1000 Hz 鸣叫 100 ms，并通过 UART 发送：

`MODE=n\r\n`

ALARM 状态下，有效按键事件不改变 `display_mode`，而是将本次报警的 `mute` 设置为 1，并立即关闭有源蜂鸣器；报警灯光仍应保持。通过 UART 发送：

`MUTE=1\r\n`

Touch 按下时产生一次有效事件，持续触摸不得重复触发。每次有效触摸使 `threshold` 在 70 和 85 之间切换。阈值改变后清零原有连续采样计数，从下一次 ADC 采样开始按照新阈值重新累计。切换成功后，无源蜂鸣器以 2000 Hz 鸣叫 100 ms，并通过 UART 发送：

`THR=n\r\n`

### 第 5 题：超限报警与状态优先级（20 分）

当连续 3 次 ADC 采样均满足 `level` 大于或等于 `threshold` 时，系统进入 ALARM 状态。单次异常采样不得触发报警。

ALARM 状态下：

1. 全彩 LED 强制显示红色，亮度为 128。
2. LED4 以 250 ms 为翻转间隔持续闪烁，LED1、LED2、LED3 熄灭。
3. `mute` 为 0 时打开有源蜂鸣器；`mute` 为 1 时有源蜂鸣器保持关闭。
4. 报警显示优先级高于 NORMAL 状态的两种显示方式，但不得修改 `display_mode` 和 `threshold`。

当连续 3 次 ADC 采样均满足 `level` 小于或等于 `threshold - 10` 时解除报警，系统回到 NORMAL 状态。解除报警后应关闭有源蜂鸣器、停止 LED4 闪烁、将 `mute` 自动恢复为 0，并按照当前 `display_mode`、`threshold` 和 `level` 恢复正常显示。

LED4 闪烁必须由周期定时事件驱动，不得在任务中使用 250 ms 的阻塞延时实现。

### 第 6 题：UART 查询与控制（15 分）

UART 波特率为 115200，上位机发送的命令以 `\r\n` 结束。系统至少支持以下命令：

1. `GET`：返回当前完整状态，格式为：

   `LEVEL=xx MV=xxxx THR=tt MODE=m STATE=s MUTE=u\r\n`

2. `MODE n`：`n` 只能为 0 或 1，立即设置 `display_mode`。
3. `THR n`：`n` 只能为 70 或 85，立即设置 `threshold`，清零原有连续采样计数，并从下一次 ADC 采样开始按照新阈值重新累计。
4. `MUTE`：仅在 ALARM 状态下将 `mute` 设置为 1，并关闭有源蜂鸣器。

`MODE n`、`THR n` 和 `MUTE` 执行成功时统一返回 `OK\r\n`；`GET` 只返回规定的完整状态行。命令不完整、无法识别、含有多余字符或参数越界时返回 `ERROR\r\n`。串口可能出现半包或连续多条命令，解析期间不得影响 ADC、按键、Touch 和报警闪烁。

通过 UART 修改模式或阈值时，应与按键或 Touch 修改产生完全相同的显示和保存效果。

### 第 7 题：NVS 掉电保存（10 分）

系统应将 `display_mode` 和 `threshold` 保存到 NVS。通过按键、Touch 或 UART 修改成功后，应立即更新对应数据。

重新上电时，应在创建业务任务前读取并恢复配置。如果键不存在、读取失败或数据超出有效范围，使用以下默认值：

- `display_mode = 0`
- `threshold = 70`

`level`、`system_state` 和 `mute` 不保存。重新上电后，系统必须重新采样并判断是否报警。

## 五、现场验收要求

1. 能够观察到规定的 3 秒自检状态和 `READY` 串口信息。
2. ADC 输入变化时，`level`、普通 LED 和全彩 LED 显示对应正确。
3. 按键长按和 Touch 长按均只能触发一次有效事件。
4. 两种普通 LED 显示方式能够正确切换。
5. 修改阈值后，系统能够立即按新阈值执行后续判断。
6. 单次高值不得触发报警；连续 3 次高值应进入报警。
7. 报警状态下按键能够静音，但不能取消红色报警显示。
8. 输入下降并满足解除条件后，系统能够恢复报警前的配置和正常显示。
9. UART 命令、错误回复、半包和连续命令处理正确。
10. 修改模式和阈值后重新上电，NVS 数据能够正确恢复。
11. 任意功能运行时，不得出现看门狗复位、任务栈溢出或其他功能长时间失去响应。

## 六、评分说明

现场验收按各题功能完成度计分。若某项功能仅能偶尔成功、存在明显阻塞、持续重复触发、状态互相覆盖或导致系统复位，该项不能获得满分。未使用指定输入输出资源、未满足规定协议格式或使用阻塞延时代替指定定时事件时，按对应功能缺失计分。

本题满分 100 分，建议验收顺序为：上电自检、ADC 与显示、按键和 Touch、报警与静音、UART 控制、NVS 掉电恢复。
