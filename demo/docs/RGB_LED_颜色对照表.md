# RGB 灯带颜色对照表

本表用于给 WS2812 RGB 灯带手动调色。每个颜色同时给出 RGB 和 HSV 两种写法，可以直接用于 `RgbLed_SetPixel()`、`RgbLed_SetPixelHsv()`、`RgbLed_Fill()` 或 `RgbLed_FillHsv()`。

## 两种调色方式

```c
/* RGB：直接指定红、绿、蓝三条发光通道，取值都是 0~255。 */
RgbLed_SetPixel(0, 255, 127, 0);

/* HSV：指定色相、饱和度、明度。 */
RgbLed_SetPixelHsv(0, 30, 255, 255);
```

上面两种写法都会让第 0 颗灯显示橙色。设置完成后，调用一次 `RgbLed_Refresh()` 才会真正发送到灯带：

```c
RgbLed_Refresh();
```

## HSV 参数说明

| 参数 | 范围 | 含义 | 常用值 |
| --- | --- | --- | --- |
| `hue` | 0~359 | 色相，即颜色种类 | 0 红、60 黄、120 绿、180 青、240 蓝、300 品红 |
| `saturation` | 0~255 | 饱和度，即颜色是否鲜艳 | 255 最鲜艳，128 较淡，0 无色（白或灰） |
| `value` | 0~255 | HSV 颜色自身的明度 | 255 最亮，128 较暗，0 黑色 |

色相可以想成一个圆环：`0` 和 `360` 都是红色。将 `hue` 从 0 逐步增加到 359，颜色会依次经过红、橙、黄、绿、青、蓝、紫，最后回到红色。

> `value` 只影响本次 HSV 颜色的明度；`RgbLed_SetBrightness()` 是整条灯带的全局亮度。一般先用 `value` 选颜色明暗，再用全局亮度限制灯带整体亮度和耗电。

## 白色、灰色与熄灭

当 HSV 的饱和度 `saturation` 为 0 时，`hue` 不再影响最终颜色；此时颜色只由 `value` 决定。

| 颜色 | RGB `(R, G, B)` | HSV `(H, S, V)` | 含义 |
| --- | --- | --- | --- |
| 白色 | `(255, 255, 255)` | `(任意, 0, 255)` | 三种光都最亮 |
| 浅灰色 | `(192, 192, 192)` | `(任意, 0, 192)` | 三种光都较亮 |
| 灰色 | `(128, 128, 128)` | `(任意, 0, 128)` | 三种光同样输出一半左右 |
| 深灰色 | `(64, 64, 64)` | `(任意, 0, 64)` | 三种光都较暗 |
| 黑色、熄灭 | `(0, 0, 0)` | `(任意, 任意, 0)` | 没有任何颜色输出 |

示例：

```c
RgbLed_SetPixelHsv(0, 0, 0, 255);   // 白色，hue 写多少都可以
RgbLed_SetPixelHsv(1, 0, 0, 128);   // 灰色
RgbLed_SetPixelHsv(2, 0, 255, 0);   // 熄灭
RgbLed_Refresh();
```

## 柔和颜色与暖白色

这些颜色适合做状态提示、呼吸灯或避免灯光过于刺眼的场景。

| 颜色 | RGB `(R, G, B)` | HSV `(H, S, V)` | 说明 |
| --- | --- | --- | --- |
| 淡红色 | `(255, 128, 128)` | `(0, 127, 255)` | 红色降低一半饱和度 |
| 淡绿色 | `(128, 255, 128)` | `(120, 127, 255)` | 绿色降低一半饱和度 |
| 淡蓝色 | `(128, 128, 255)` | `(240, 127, 255)` | 蓝色降低一半饱和度 |
| 暗红色 | `(128, 0, 0)` | `(0, 255, 128)` | 保持鲜艳，降低明度 |
| 暗蓝色 | `(0, 0, 128)` | `(240, 255, 128)` | 保持鲜艳，降低明度 |
| 暖白色 | `(255, 180, 100)` | `(31, 155, 255)` | 偏黄的白光，接近暖色灯光 |

## 推荐用法

### 整条灯带显示同一种颜色

```c
RgbLed_FillHsv(120, 255, 180);  // 全部灯珠显示较暗的绿色
RgbLed_Refresh();
```

### 单独修改一颗灯

```c
RgbLed_SetPixelHsv(4, 0, 255, 255);  // 第 4 颗红色
RgbLed_Refresh();
```

### 设置多颗不同颜色后统一刷新

```c
RgbLed_SetPixelHsv(0, 0, 255, 255);    // 红
RgbLed_SetPixelHsv(1, 120, 255, 255);  // 绿
RgbLed_SetPixelHsv(2, 240, 255, 255);  // 蓝
RgbLed_Refresh();
```

### 使用现成的彩虹效果

```c
RgbLed_ShowRainbow(0);  // 显示一帧静态彩虹，函数内部已经刷新
```

## 实际灯带调色建议

1. 想快速选颜色时，优先使用 HSV：固定 `saturation = 255`、`value = 255`，只修改 `hue`。
2. 觉得颜色太刺眼时，先将 `value` 改为 `80~180`；也可以使用 `RgbLed_SetBrightness()` 降低整条灯带亮度。
3. WS2812 灯珠会因批次、供电电压、外壳颜色而略有差异。表中数值是可靠的起点，最终可以根据实物效果微调。
4. 单次要修改多颗灯时，全部设置结束后只调用一次 `RgbLed_Refresh()`。
